# 0007 导出：Excel（openpyxl）

- 状态：已采纳
- 日期：2026-11-03

## 背景

处理结果要交给不看终端的人（财务、审核员）。他们要能直接筛选、排序、求和，
并且一眼看出哪些值需要确认、为什么、去原图哪里看。

## 决策

**导出插件（`plugins/exporters/`）。** `Exporter` 接口 + 登记表，第一个实现是 Excel（openpyxl，MIT 授权）。
输入是 `DocumentReport`：一张单据走完 OCR → 抽取 → 对齐 → 校验后的全部结果，加文件名和处理时间。
导出器不做判断，只按已有结果决定颜色和说明。

**Excel 三个工作表：**

- **汇总**：一张单据一行，一个字段一列。找不到出处标红，需要确认（对齐或规则）标黄，
  批注写原因和出处位置。最后一列是需要确认的数量。
- **明细**：一个字段一行：值、状态、出处、OCR 置信度、是否需要确认、原因。有筛选按钮。
- **来源**：OCR 引擎和版本、模型、后端、提示词版本、处理时间、用时。

**类型：** 日期写成 Excel 日期，金额写成数字并设置 `#,##0.00` 显示格式，方便筛选和计算。
Excel 本身用二进制浮点存数字，所以写入时不需要 Decimal；以后在 Python 里汇总金额时再用 Decimal。

**命令行：** `jacara extract 图片 --excel 路径`。输出文件建议放在 `results/`（不进 Git）。

## 后果

- 结果第一次可以直接交给用户，来源信息随文件一起保存。
- `DocumentReport` 会成为以后存数据库、网页显示的统一结构。
- 一次可以导出多张单据，批量处理时导出器不用改。
