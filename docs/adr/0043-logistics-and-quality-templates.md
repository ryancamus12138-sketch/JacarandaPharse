# 0043 v4 第 1 批：物流、送货、质检起步模板

状态：已采纳（2026-11）

起步模板从 10 个加到 16 个。和检验报告（ADR 0041）一样：字段按公开的规定、标准和真实单据上共有的要素设计，
**不放任何真实单据的内容**；规则只核对单据自己前后一不一致，不替人做判断。

| 模板 | 依据 | 规则 |
|---|---|---|
| 检验检测报告（质检报告）`quality_report` | ISO/IEC 17025:2017（GB/T 27025-2019）7.8.2.1 规定的报告内容：标题、机构、唯一编号、委托方、方法、样品、接收日期、检测日期、签发日期、结果和单位、批准人；加上产品质检报告常见的规格型号、批号、生产单位、单项判定、结论 | 有一项不合格结论却写合格（或全部合格结论却写不合格）；收样晚于签发 |
| 装箱单 `packing_list` | 外贸单证装箱单的通用要素：发票号、合同号、唛头、港口、每行箱号、件数、数量、净重、毛重、体积和合计 | 件数、数量、净重、毛重、体积各自加起来 = 合计；净重不超过毛重 |
| 送货单 `delivery_note` | 国内企业送货单（发货单、出库单）的通用要素 | 数量 × 单价 = 金额；金额合计；数量合计 |
| 快递 / 货运运单 `cn_express_waybill` | GB/T 28582《快递运单》和快运、零担托运单共有的栏目；寄件人、收件人的姓名、电话、地址标成敏感 | 运费 + 保价费 + 包装费 + 其他 = 费用合计 |
| 海运提单 `bill_of_lading` | UCP 600 第 20 条对提单的要求（承运人、装卸港、已装船批注和日期、正本份数）和提单正面的通用栏目 | 集装箱号校验位（ISO 6346）；集装箱件数、毛重、体积加起来 = 合计；装船日期不晚于签发日期 |
| 航空运单 `air_waybill` | IATA 第 600a 号决议的航空运单栏目 | 运单号校验位（序号前 7 位 ÷ 7 的余数 = 第 8 位）；运价行件数、毛重加起来 = 合计；计费重量 × 费率 = 运费 |

细节：
- 合计核对的容差取合计的千分之五和 0.015 中大的那个（重量、体积常四舍五入）；都是"提醒"级别。
- 计费行运费对不上只提醒：M 类（最低运费）本来就不是重量 × 费率。
- 质检结论只认"合格 / 不合格 / 符合 / 不符合 / Pass / Fail"这类明确的字眼，读不出的不查。
- 字段 ID 和已有模板一致（`total`、`issue_date`、`items`），送货单直接用上已有的 `item_line`、`items_sum`。
- 前端"功能领域"的建议词加上 检验报告、质检、外贸单证、采购。

顺带：三个收据模板升到 v3，`document_no` 加了 Document No、Doc No、Bill No 等别名，`merchant_tax_id`、
`time`、`rounding` 也补了别名。成对测评（ADR 0042）里收据的"Document No"因为别名没写到而漏找，补上后能找回。
