# 0038 自动判断用哪个模板、让模型看原图（v3 第 3 批）

状态：已采纳（2026-11）

## 背景

- 上传时每次都要选模板。一批文件里混着发票、小票、酒店账单时，要么分几次传，要么传完一张张重新处理。
- 模型只看 OCR 认出来的文字。照片和扫描件上有手写、印章、模糊、反光的地方，OCR 会认错或漏掉，
  模型给出的值在原文里对不上，按 LMDX 的规则（ADR 0034）被丢掉，审核时要人自己对着原图补。

## 决定

### 自动判断用哪个模板

上传、监视文件夹（`JACARA_WATCH_TEMPLATE=auto`）、重新处理都可以选"自动判断"。documents 加一列 `auto`。
一个文件里有几张单据（ADR 0036）时，每张单据各选各的模板。

每张单据（`pipeline/classify.py`）：

1. **关键字打分**：每个"我的模板"（没归档、没删）的字段中文名、别名、模板名在单据文字里出现了多少，
   算成"对上的字段占几成"。不用模型，很快。
2. **模型挑**：分数最高的 5 个模板的说明（名字、说明、功能领域、国家和地区、字段，ADR 0037）
   和单据开头 60 行文字交给模型（提示词 classify-v1），模型选一个，或者选 0（都不合适），并写一句理由。
3. **都不合适**：不用模板，抽出所有键值对，审核时可以存成新模板。
4. 没有模型可问、模型回答不合格时，按关键字分数选；分数低于 0.3 当作都不合适。

选的结果记在每张单据上（extractions 加 `classified`：选了哪个、理由、谁选的、比较过的模板和分数），
`template_version_id` 记选中的版本。审核页顶上显示"自动判断：酒店账单"，点开看理由和候选。
选错了用"重新处理"换模板；重新处理不换模板时再自动判断一次（模板改了、加了新模板都会用上）。
模板页"几份文档用过"也算上自动判断选中的。

只在"我的模板"里选，不在起步模板库里选：起步模板没有加进来，说明用户不需要它；
而且结果要能按模板版本还原（ADR 0030）。

### 让模型看原图

模型服务加载视觉模型（mmproj）后能看图。Qwen3.5-9B 配套的 `mmproj-F16.gguf`（Apache-2.0，约 918 MB）
由用户自己下载放进 `models/`，`jacara start`、`jacara serve` 发现了就加上 `--mmproj`。
是否能看图问模型服务的 `/props`（`modalities.vision`），没加载就当不能看，照常只看文字。

什么时候看（`JACARA_VISION`，`pipeline/vision.py`）：

- `auto`（默认）：单据里有一页是照片或扫描件（不是 PDF 文字层），而且 OCR 不可靠：
  平均置信度低于 0.88、两成以上的文字块置信度低于 0.75，或者只认出不到 5 块字；
- `always`：每张都看（慢，适合手写多的）；`off`：不看。
- 重新处理时可以对这一份文档单独选"每张都看 / 不看 / 按系统设置"（documents 加一列 `vision`）。

看图时提示词照旧给按位置排好、带编号的文字块，另外附上每页的图（最长边 1600 像素，最多 4 页），
并说明：OCR 认错的写图上看到的值、blocks 写认错的那几块；OCR 漏掉的 blocks 写空。
提示词版本记成 `extract-v7+vision`，extractions 加 `vision` 记为什么看了图。

证据对齐（ADR 0034）多一种状态 **seen（看原图读的）**：看了图、值在文字里对不上时不再丢掉，
值留着、标黄要人核对；模型说了是哪几块认错的，就框那几块，说明里写"OCR 认成「…」，模型看到的是「…」"。
没看图时和以前一样按规则丢掉（rejected）。

### 审核时"让模型看这块"

审核页框选（ADR 0029 的"框选 → 重新识别这块"）多一个按钮"让模型看这块"：
把框里这一块裁下来（四周多留一点，小的放大到至少 64 像素、大的缩到 1024 像素以内），
连同要填的字段名和类型交给视觉模型（提示词 look-v1），模型回答图里的文字和这个字段的值。
结果只显示、不保存，人核对后点"填入"，修改记录的原因写"模型看原图读的，人核对过"。
接口 `POST /documents/{id}/pages/{page}/look-region`；模型服务没加载视觉模型时返回 503，
前端用 `GET /system/vision` 决定显不显示这个按钮。

重新处理里的选项叫"对照原图读"：系统决定（推荐）/ 每页都对照原图 / 只看文字（最快），
默认选中这份文档现在的设置；没有视觉模型时整组变灰，并说明怎么放。

### 核对出处：24 小时制的时间、少认了小数点的数字

- 时间字段：模板让模型写成 24 小时制（20:13:39），单据上写 8:13:39 PM，以前文字比对不上被丢掉。
  现在时间按时钟比：24 小时制和 12 小时制（AM/PM）、带不带秒都算对上。
- 数字字段：模型说的那几块里没有这个数时，再看和那几块同一高度的文字块：
  一样的数字（模型说错了块），或者少了小数点的写法（1.00 被笔迹盖住小数点、OCR 读成 100）。
  找到了值留着、标黄，说明里写原文是什么，让人看一眼。

## 没做的

- 不在起步模板库里自动选；不自动建新模板。
- 不让视觉模型给出处的坐标：出处框只来自 OCR 文字块，看图读的值框的是 OCR 认错的那几块，或者没有框。
- 键值对发现（不用模板）不看图。
