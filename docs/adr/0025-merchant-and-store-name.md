# 0025：商家是开票的公司，店名另起一个字段

- 状态：已采纳
- 日期：2026-11-11

## 背景

SROIE 626 张的全量评测里，商家的准确率只有 65.7%，而且错的几乎都没被标黄（拦截率 5.1%），
"没标黄就可以信"在商家上不成立。215 个错例里，约 76 个是收据上同时有店名和公司名
（如 `BAR WANG RICE` 和 `UNIHAKKA INTERNATIONAL SDN BHD`），模型选了店名；约 73 个多抄了公司注册号、分店名。
根本原因是"商家"没有定义清楚。

## 决定

1. **merchant = 开这张收据的公司名**（"商家（公司）"）：对账、报税用的是它，和 SROIE 的标准答案一致。
   只抄公司名本身，不带括号里的注册号、分店名、地址、电话。收据上只有店名时，才填店名。
2. **新增 store_name = 顾客看到的店名或品牌名**（"店名"），给人一眼认出是哪家店。和公司名一样时照抄。
3. 这是 receipt 模板第 2 版（`receipt_full` 同步为第 2 版，15 个字段）。
4. 说明里的例子不用评测集里的真实店名和注册号，避免评测分数虚高。
5. 评测加"宽松准确率"（文字相似度 ≥ 90% 算对），把 OCR 错字（约 51 个）和真正抽错分开看。
   OCR 错字不在这一版处理：模型按规定照抄原文，错字要靠 OCR 置信度或人工确认。

## 影响

- 新上传的文档多一个"店名"字段；旧文档不变（模板版本记为 1）。
- SROIE 没有店名的标准答案，store_name 暂不评测。
- 发票模板也会遇到同样的问题（销售方名称 vs 店名），沿用这个定义。
