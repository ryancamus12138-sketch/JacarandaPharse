# 0048 模板多语言、按地区管理、中国版质检报告

日期：2026-11-13
状态：已采纳

## 背景

起步模板要覆盖更多国家和地区。用户要求：

1. 每个模板都能切换中文、英文和当地语言（审核页的字段名、导出的列名）；
2. 模板按地区管理：通用模板一组，各国、各地区一组；
3. 只有法律对单据有不同要求的，才单独做某个国家的模板；通用模板靠切换语言，不复制成多份；
4. 每个模板都要有法律依据和实际使用场景，查不到依据的不做。

## 决定

### 多语言名字

- 字段、表格、表格的列可以写 `names = { en = "...", ja = "..." }`，模板可以写 `titles = { ... }`。
  `label`、`title` 还是默认的中文名，没写的语言一律显示中文。
- 语言代码用 BCP 47 的简写（`zh`、`en`、`ja`、`zh-Hant`……），写错了模板加载时说清楚。
- 别的语言的名字也告诉模型"单据上可能这么写"（和别名合并、去重），日文、德文单据上的标签更容易对上。
- 审核页"字段名"下拉框切换（按模板记在浏览器里）；导出的"列名语言"和它共用。
  导出接口加 `lang` 参数（`/documents/export.xlsx?ids=...&lang=en`），表头里文件名、页码这些固定列还是中文。
- 模板编辑器右上角选"名称语言"，名称一列就改那种语言的名字。
- 我的模板的 `titles`、`names` 存在定义（JSON）里，不用改数据库表。

### 按地区管理

起步模板库按地区分组显示：通用（不分国家）在前，然后中国、澳洲，其余按国家名。地区就是模板的 `countries`。

### 中国版质检报告（`cn_quality_report`）

中国对检验检测报告有通用模板（ISO/IEC 17025）之外的要求，所以单独做一份：

- 《检验检测机构资质认定管理办法》（市场监管总局令第 38 号）第二十一条：向社会出具具有证明作用的数据、
  结果，应当在报告上标注资质认定标志；国认实〔2015〕49 号：标志由 CMA 图案和 12 位证书编号组成。
- 《检验检测机构监督管理办法》（市场监管总局令第 39 号）第十一条：加盖公章或检验检测专用章，授权签字人签发。
- 《检验检测机构资质认定评审准则》（2016 年版）4.5.20、4.5.22：机构地址、每页标识、客户地址、
  样品状态、抽样日期和地点等。

新规则：`cn_cma_no`（证书编号是 12 位数字）、`cn_sampling_dates`（抽样日期不晚于签发日期），只给中国模板用。

化验单模板本来就按《医疗机构临床实验室管理办法》（卫医发〔2006〕73 号，2020 年修订）第十七条设计，
字段和中国的要求一致，不另做中国版。送货单、收据、酒店账单在中国没有法定格式，不单独做。

### 起步模板都加了英文名

17 个起步模板的字段、表格、模板名都加了英文名，版本号各加 1（提示词里多了英文写法）。
物流、外贸单证用单据上的标准英文（IATA 航空运单、提单上的写法）。

### 规则跟着模板走

- 模板编辑器的"规则"只列跟这个模板有关的：已经选了的，加上要用的字段模板里都有、而且是通用规则或
  本模板国家的规则。去掉了"显示全部"：化验单不会再列出发票、ABN、提单的规则。
  想用某个国家的规则，先在"国家和地区"里选上那个国家（取代 ADR 0037 里"我的模板可以选任何规则"）。
- 保存时去掉跑不了的规则：删了字段、去掉了国家，依赖它们的规则跟着去掉，不会留着永远跳过。
  编辑时这样的规则标"保存时会去掉"。导入模板文件、用样例建模板也一样（文件里没写国家的只按字段筛）。
- 导出模板 Excel 的"规则"表只列选了的规则。

## 影响

- 当地语言的名字随各国模板一批批加（做日本模板时，通用模板也加日文名）。
- 各国模板逐个查官方规定，出处写在模板文件开头和 ADR 里；查不到依据的不做。
