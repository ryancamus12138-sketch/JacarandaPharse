## 检验报告（化验单）起步模板

`templates/starters/lab_report.toml`，通用（不分国家），功能领域"医疗、检验报告"。

字段按真实报告上的要素设计，不放任何真实报告的内容：
- 《医疗机构临床实验室管理办法》（2006）规定临床检验报告要有的内容：实验室名称、患者姓名、性别、年龄、
  病历号、检验项目、结果和单位、参考范围、异常提示、操作者、审核者、标本接收时间、报告时间；
- ISO 15189:2022 7.4.1.6：标本类型、采集时间；
- 每一项检验结果的五个字段（项目、结果、单位、参考范围、异常提示）和 MedRepBench 论文
  （arXiv 2508.16674）的结构一致。论文的数据集还没公开，这里只参考了结构。

患者姓名、病历号、临床诊断标成敏感（默认不导出）。标本号标成"不能重复"。
结果是文字（阴性、+、<0.1 都要能写），高低箭头单独一列。

新规则 `lab_flag`（每一行，警告）：数字结果和数字参考范围（3.5-9.5、<5.0、≥1.0）对比，
超出范围却没标 ↑/↓（H/L、高/低），或者在范围内却标了，就提醒。定性结果、读不出的参考范围不查。

从 Excel 建模板时，表头像检验报告的会匹配到这个起步模板，借用它的字段类型（结果按文字）。

## 导出 CSV

`GET /documents/export.csv?ids=…`：内容和汇总 Excel 一样（一行一张单据；日期范围按模板设置，
拆成两列的就是两列）。UTF-8 带 BOM，Excel 直接打开不乱码；日期写 2014-08-03，数字不带千分位。
只有汇总一张表时下载一个 .csv；还有明细表、键值对时，每张表一个 .csv 打包成 zip。
"明细"（逐个字段的出处和审核）和"来源"不导出。导出记录里格式记 csv / csv-zip。

## 原表的列对到日期范围

从 Excel 建的模板，编辑器"Excel 结构"里每一列填什么可以改（`TemplateIn.column_refs`，
键"sheet 名::表头"）。日期范围字段可以选"统一格式""开始""结束""天数"，
例如原表的"开始日期""结束日期"两列对到同一个日期范围字段的开始、结束。
sheet 的角色、对象、参照表仍然不能改。
