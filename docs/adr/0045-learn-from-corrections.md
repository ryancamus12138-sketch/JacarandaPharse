# 0045 v4 第 3 批：从人改过的地方学

状态：已采纳（2026-11）

不训练、不微调模型：抽取时在提示词里多一段"以前人工审核同一种单据时改过这些地方"（`pipeline/learn.py`）。

- 例子从哪来：同一个团队、同一个模板（`extractions.template`）、审核完成的单据，现在那一轮里模型给的值
  被人改过的字段，新的在前；最多看最近 200 张。
- 不用的：敏感字段（别人的姓名、病历号、电话不放进另一张单据的提示词）、这张单据自己（重新处理时）。
- 挑法：改得多的字段优先，每个字段最多 2 条，一共最多 8 条（太多占上下文，也会让模型照抄）。
- 写法：模型漏了的写"原文其实有，要仔细找"，多给了的写"应该给 null"，其他写"模型写成 A，人改成 B（小数点）"；
  开头说明这是别的单据上的例子，**这张单据的值一律按它自己的原文，不要照抄**。
- 追溯：提示词版本记成 `extract-v8+lessonsN`；审核页顶上显示"参考了以前改过的 N 处"。
- 开关：`.env` 的 `JACARA_LEARN`，默认打开。找例子出错不影响处理。

## 怎么证明有用

例子会不会让模型更准，要量：导出审核数据（ADR 0044），再

```bash
uv run jacara eval pairs --manifest data/eval/导出的文件夹/pairs.toml --server http://127.0.0.1:8080
uv run jacara eval pairs --manifest data/eval/导出的文件夹/pairs.toml --server http://127.0.0.1:8080 --learn data/eval/导出的文件夹/train.jsonl
```

第二次每张单据用别的单据的例子（留一法：不用它自己的），比较两次的字段准确率和"错了没标黄"。
审核过的单据少的时候例子也少，先攒够同一个模板几十张再看。
