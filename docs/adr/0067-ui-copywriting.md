# 0067 界面文案规范

日期：2026-11-14
状态：已采纳

## 背景

界面上的说明、提示、报错原来按口语写（"点一下""弄坏了""别反复看""开着/关着""去……里选"），
不够规范，也不统一：同一件事在不同页面叫法不同（"认错字 / 识别错误""存成 / 保存为""改 / 修改 / 编辑"）。
用户要求全站改成工程化、专业的说明文字。

## 决定

按 Ant Design 文案规范（本项目的界面组件就是 Ant Design）和《标点符号用法》（GB/T 15834—2011）统一改写，
范围是网页的全部文字（`web/src`，`t()` / `msg()`）和后端返回给网页、写进导出文件的全部文字（`tr()` / `stored()` / `N_()`）。
命令行输出、开发用的评测报告不在范围内（ADR 0065 已说明它们给开发者看）。

### 规则

- 书面语，不用口语：点一下 → 点击；弄、搞 → 处理；拿 → 获取、使用；看一眼 → 核对；
  不用 / 不用写 → 无需 / 选填；能 / 要 → 可 / 需；没有 / 还没 → 无、未、暂无、尚未；
  开着 / 关着 → 已开启 / 已关闭；删掉 → 删除；存成 → 保存为；建 → 创建；找 → 搜索、查找。
- 先说结论，再给下一步：报错写"无法……""……无效""……不存在"，后面给出处理方法；不用"失败了""不对"这类含糊的说法。
- 同一事物同一叫法（下表）。按钮名称和它打开的页面标题一致。
- 称呼用户用"你"，不用"您"；语气是引导而不是命令。
- 数字用阿拉伯数字，中文和数字、英文之间加空格（"2 个""50%"另按习惯）。
- 标签、标题、输入框占位、单句提示不加句号；多句说明加句号。
- 中文提示里不写"中文名"这类假定语言的词：模板可以用任何主语言（ADR 0066），一律叫"名称"。

### 统一叫法

| 用 | 不用 |
|---|---|
| 识别错误、识别正确的行、漏识别 | 认错字、认对的行、漏认 |
| 保存为模板、创建模板 | 存成模板、建模板 |
| 编辑（按钮）、修改（动作） | 改 |
| 文本框（检测样本） | 框（单独使用时） |
| 划分（train / val / test） | 边 |
| 内置（RapidOCR、模型自带的） | 自带 |
| 当前使用 / 使用中 | 现在用的 / 在用 |
| 选填 | 可以不写、可不填 |
| 读取自原图 | 看原图读的 |
| PDF 文本层 | PDF 文字层、PDF 自带的文字 |

### 已存进数据库的说明（以后改措辞时）

后台写进数据库的说明按"原文 + 参数"存，显示时再翻译（ADR 0065）。这次改写在首个公开版本之前，没有需要兼容的旧记录。
发布以后如果再改 `stored()` / `N_()` 的措辞，旧记录里存的仍是旧原文：到那时新建
`backend/src/jacara/core/i18n_legacy.py`，用 `N_()` 列出旧原文（只为留在翻译目录里），英文界面看旧记录仍能翻译。

### 标准模板工作簿的格式

当前布局是格式版本 1（首个公开版本）。表头一并按本规范改写（「名称」「字段 ID」「表格名称」「启用」等），
字段表和表格表有「公式」「不能重复」「日期范围导出」「分隔符」，每种其他语言一组「名称（en）」「说明（en）」列
（表格表另有「表格名称（en）」「表格说明（en）」），模板表有「主语言」和「模板名称（en）」「说明（en）」行，
规则表有「条件」「逐行检查的表格」（有条件的行是自定义规则）。模板的全部内容都能经 Excel 往返（`test_standard_workbook.py`）。

### 以后改格式的通用办法

参照 Protocol Buffers"更新消息类型"的规则（新增字段要有默认值、读者跳过不认识的字段、删除的字段名保留不再使用）。
下面四个机制从版本 1 起就生效，以后升级格式只需要往表里加条目，不用再写兼容代码：

- **格式版本**：模板表的「格式版本」写 `FORMAT_VERSION`。版本高于当前程序的文件直接拒绝并提示升级。
  这一条必须在第一个版本里就有：已经装在用户电脑上的旧程序，要靠它才能认出"这是新版导出的文件"，事后补不上。
- **缺少的列和项目取默认值**：公式为空、不能重复为否、日期范围按统一格式和 ` ~ `、主语言为 zh、
  没有其他语言的文字、没有自定义规则。新增列只追加在已有列之后，旧文件读进来自然取默认值。
- **不认识的列和项目**：照常导入其余内容，并在导入确认框里列出被忽略的列名和模板表项目，便于发现表头写错。
- **改名和删除**：`workbook/standard.py` 里有两张表，版本 1 都是空的。改了表头，把旧写法加进 `FORMER`
  （新写法 → 旧写法，旧写法同样认中英两种语言）；删了一列，把列名加进 `RETIRED`（认得它、直接跳过、不提示，名字不再挪作他用）。

### 格式版本记录

每次升级格式，在这张表里加一行，并按上面的办法改 `FORMAT_VERSION`、`FORMER`、`RETIRED`。

| 版本 | 程序版本 | 新增 | 改名（旧 → 新） | 删除 |
|---|---|---|---|---|
| 1 | 首个公开版本 | 全部列（见上文"标准模板工作簿的格式"） | — | — |
