# 0047 v4 第 5 批：在样例上框选建模板

状态：已采纳（2026-11）

第四种建模板的办法（前三种：手写字段、从 Excel 建、"抽取所有键值对"后存成模板）：
在任何一份处理过的单据上，打开"框选建模板"（审核页顶上，要"管理模板"权限），在原图上框住一个个值。

- **先给出读到的键值对**：处理单据时版面分析（ADR 0034）已经把"标题 → 值"配好、存在每张单据里。
  页面直接把这些值用虚线框标在原图上，右边也列出全部；点一下就加成字段，名称用它的标题，不用再猜。
- **自己框**（`POST /documents/{id}/pages/{page}/describe-region`，只看不存）：没有配对的值自己拖框。
  - 值：先用这一页存下的 OCR 文字块（一半以上落在框里的），没有再局部重新识别；
  - 标签：**只查版面分析配好的结果**（配对的值大部分在框里、框也大部分是这个值）。查不到就留空，
    不按位置猜；名称旁边点"瞄准"，再点原图上的标签文字就填上；
  - 类型：整段是一个数（可以带货币、单位）→ 数字；有明显"到"的两个日期 → 日期范围；能读成日期 → 日期；其他文字；
  - 位置：页面分 3 × 3 格（右上角、下方中间……）；字段 ID：英文标签直接转（Invoice No → invoice_no），中文不猜。

### 第一版为什么标签总是错（2026-11 改掉）

第一版没用版面分析的结果，另写了一条"同一行往左找最近的一块，没有再看正上方"的规则：
标签在值上面的排版（Check In / 31/12/2017）会抓到左边一栏的字，表格里会抓到中间一列，
分不清标签和别的值（把 IBZY2087 当成 Payment Mode 的标签）。改成直接查版面分析的配对；
同时修了版面分析两处（正着抽取也一起变好）：
- 值往下接折行时，下一行左边如果有自己的标签（"Cashier : MANIS"），就不是折行，不接；
- 没认出表格的表格行（"Room Charges   Rs 1939 x 1 Night   Rs 1939"）：最左边像标题、不带数字、
  不以冒号结尾，同一条水平线上右边还有两块以上、最右边是金额，配成"行名 → 金额"（规则 row_label）。
  按位置判断同一条线，不按行号：行名和金额有时被分在两个版面区域里。
已经处理过的单据存的是旧的配对，重新处理一次才会用上新规则。

- **存成模板**（`POST /templates/from-boxes`）：标签记成别名（按标签找漏读的值、模型认字段都用得上），
  位置写进字段说明（"在单据右上角，「Invoice No」右边"，模型看得懂）。框的坐标不进模板定义：
  模型按文字和版面理解单据，同一种单据位置稍有变化也能找到；不做"按坐标裁图取值"那种只认固定版式的做法。
- 存好后可以直接"用新模板重新处理这份样例"，看模型按新模板抽得对不对；或者去模板编辑页加表格、规则。
- 表格（商品明细）不在这一步框，保存后在模板编辑页里加。
