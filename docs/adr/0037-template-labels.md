# 0037 模板标签：功能领域、国家和地区、自定义标签

状态：已采纳（2026-11）

## 背景

模板以前只有一个"类型"（发票、收据、住宿……）和一个"地区"（通用 / 中国 / 澳洲）。
地区写在模板定义里，保存时会检查：通用模板不能用地区规则，地区模板只能用本地区的规则。
这样有三个问题：

- 用户自己的模板被卡住了。导入一份老的中国发票 Excel 会报"这是通用模板，不能用别的地区的规则"。
- 国家只有两个，别的国家的模板没法标。
- 模板多了以后找不到，没有按领域、按国家筛选的办法。

## 决定

每个模板有三组标签，像微信的标签分类一样，一个模板可以带好几个：

- **功能领域**：可以多选，比如发票、收据、交通、住宿、餐饮、购物。以前的"类型"直接变成第一个领域。
- **国家和地区**：ISO 3166 两位代码（CN、AU、US……），可以选任何国家，也可以多选。不选就是"通用"。"通用"和具体国家互斥，选了国家就不是通用。
- **自定义标签**：用户自己写，比如"2026-10 出差""财务部"。现在是个人版，先只做个人的。

标签存在 `templates` 表的 domains、countries、tags 三列（JSON）。它们不算模板定义，不进版本：
只改标签或名字，不会生成新版本。导出的 TOML 和 Excel 带上领域、国家和地区，导入时读回来。
老文件没写国家，就按里面用到的规则推断（用了中国发票规则就是 CN）。

规则的限制分两种情况：

- **起步模板库**（我们写的）照旧要求严格：通用模板只用通用规则，某个国家的模板只用通用规则和这个国家的规则。用测试 `foreign_rules()` 检查。
- **我的模板**（复制、上传、导入、新建的）不限制，任何规则都能加。编辑器里默认只列用得上的规则：通用的，加上模板所选国家的。点"显示全部"能看到别的国家的、缺字段的规则。

模板管理页加筛选：

- 按名字和说明搜索。
- 一排按功能领域、一排按国家和地区、一排按自定义标签，后面带数量，点一下只看那部分。
- 按来源（自己建的、从起步模板复制的、导入的）筛选。
- 排序：最近修改、最近用过、用得最多、名字。

卡片上显示用过它的文档有几份、最近一次是什么时候。

## 后果

- 迁移 `b3d8f1a6c2e9` 加三列，把以前的类型、地区（或者从规则推断的国家）填进去。
- 规则表 `REGIONS` 的值改成国家代码。
- 上传时选模板的下拉按第一个领域分组，可以按国家名搜索。
- 团队版以后要加团队共享的标签，再单独设计。
