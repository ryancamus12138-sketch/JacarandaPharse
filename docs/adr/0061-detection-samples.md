# 0061 检测样本：整页图片和文字框，人在系统里调框、确认后导出

状态：已采纳（2026-11）。完成 ADR 0050 第二批里的"整页图片和多边形，给检测模型用"。

## 为什么

ADR 0050 只收单行小图，训练识别（rec）模型用。文字检测（det）模型漏框、框歪时，识别再好也读不出来；
训练检测要整页图和每一行字的框。

## 参照

PaddleOCR 的标注工具 PPOCRLabel：先用现有模型"自动标注"出框和文字，人逐页调整（拖角、加框、删框、改字），
确认一页打一个勾（记在 `fileState.txt`），只有确认过的进 `Label.txt`。系统里照这个流程做，不另起一套
（PaddleX 文档"文本检测/文本识别 标注"）。

## 哪些页可以做

- 审核完成（reviewed）的单据，当前一轮，OCR 认的页（PDF 自带文字的页不要：框不是检测模型给的）。
- 这一页上有敏感字段的出处时不做：整页图会带上它（敏感字段打码还没做，ADR 0050 同样不收敏感字段）。

## 预标注

打开一页时第一次生成，之后只改这份：

- OCR 快照里这一页的每个文字块：四个角和文字；
- 已收的 OCR 样本（ADR 0050）里人改对的图中原文，替换同一块（同一个四边形）的文字；
- 框选的"漏认"样本（`missed`），加成新框，文字是人填的图中原文。

## 框编辑器

审核工作台旁边一页"检测样本"：页面图上画出所有框。

- 选中框：拖四个角改形状、拖框整体移动、`Delete` 删掉；右边改文字；勾"看不清"（导出成 `###`，不参与训练）。
- 在空白处拖一个矩形加新框。
- "保存"；"确认这一页"（PPOCRLabel 的确认）；"不用这一页"。保存带修订号：两个人同时改，后保存的会被拒绝、
  要刷新再改。
- 框只有四个点（PaddleX 文字检测标注：四个顶点，从左上开始顺时针），不做弯曲文字的多点框。

## 导出

- 只有确认过的页。按 ADR 0052 的业务单据分组分训练、验证、锁定测试集，隔离的组不导出（规则和识别样本一样）。
- zip：`images/p_0001.png`（文件名只是编号）、`det_gt_train.txt` / `det_gt_val.txt` / `det_gt_test.txt`
  （每行 `图片路径<Tab>[{"transcription": …, "points": …}]`，PaddleOCR 检测训练直接读）、`manifest.jsonl`、`README.md`。
- 可以下载，也可以存进数据集库（ADR 0059），给检测模型评测用（ADR 0060）。
- 权限：调框和确认要"修改和确认字段"（`value:review`）；导出要"导出"（`document:export`）。保存、确认、导出记审计日志。
