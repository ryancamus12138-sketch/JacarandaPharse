# 0050 OCR 纠错样本：审核时收集，导出成 PaddleOCR 识别训练数据（第一批）

状态：已采纳（2026-11）

ADR 0044 导出的 train.jsonl 存的是"审核后的业务值"（`2024-05-17`），训练 OCR 要的是"图上写的字"
（`17/05/24`）和那一块图，所以训不了识别模型。这一批在审核时顺手把 OCR 认错的地方存成
"一张单行小图 + 图上原样的文字"，按 PaddleOCR 识别（rec）训练的格式导出。只做识别，不做检测（找字）。

## 开关

"OCR 样本"页顶上的"自动收集纠错样本"，按团队存（表 `team_settings`，键 `collect_ocr_samples`），
默认关；只有管理员能改（`system:manage`），改动记审计日志。关着的时候审核和以前完全一样。

## 审核时怎么收集

开关打开后，审核页多一个"图中原文"：

- **点一块原文**（不按 Ctrl / ⌘ 的单击）：不再直接填入，先弹出"图中原文"，里面是这块 OCR 读的文字，
  按图改对，Enter 填入。字段值从改好的原文读出（日期、数字照旧转成业务格式）。
  一次只针对一块：按住 Ctrl / ⌘ 选好几块的，照旧直接填，不收集。
- **框选**：重新识别以后，填入的文字默认就是"图中原文"；框里还有别的字（例如标签"日期："）、
  和要填的值不一样时，点"单独填写图中原文"分开写。

保存审核（`POST /values/{id}/revisions` 多一个 `transcription`）成功的同时收集，不另外点按钮。
只选框、取消、没保存的都不收集。以下情况只保存审核、不收集：开关关着；敏感字段；这一页的文字是
PDF 自带的（不是 OCR 认的）；没有原文件；原文里有 Tab、换行；选了好几块原文。

## 一条样本

- **裁图**：
  - 点的是一块原文：按这块的四个角，从同一张页面图（PDF 216 DPI、照片按 EXIF 转正的原图）上
    透视裁下来、拉正，和 RapidOCR 识别时裁给识别模型的图一模一样（竖着的转 90°）。
    这样"系统读成什么"和"那张图"严格对应，能看出是识别模型的错。
  - 框选：按框裁，四周多留一点，和"重新识别这块"用的图一样。
- **分类**（系统自动分，样本页可以改）：
  - 认错字（`rec_error`）：点的是一块原文，改过的文字和 OCR 读的不一样；
  - 认对的行（`correct`）：点的是一块原文，没改。训练时要和错例一起用，不然模型会"忘掉"认得好的字；
  - 漏认（`missed`）：框选，框里原来没有 OCR 文字块；
  - 原因未确定（`unclear`）：框选，框里有 OCR 文字块，图和首轮识别时的不完全一样，说不清是哪一步错的。
- **错误标签**（只看 OCR 读的和改后的两串字）：字认错、漏字、多字、只差空格大小写全角半角、整行没认出（标点要算：`100` 和 `1.00` 是漏字）。
- 存的：裁图（对象存储 `ocr-samples/<团队>/<id>.png`）和它的 SHA-256、图中原文、OCR 读的（没有 OCR
  文字块是空）、分类、标签、模板、字段、PDF 还是照片、OCR 引擎版本、页码和四个角或框、关联的审核记录。
- 裁图出错不影响审核：审核照样保存，样本标"裁图失败"，样本页可以重试。
- 删除文档时它的样本和裁图一起删。

## 样本页和导出

菜单"OCR 样本"：按分类、状态、来源筛选；看小图、OCR 读的、图中原文；改原文和分类、撤回、恢复、重试
（要"修改和确认字段"权限，记审计日志）。

导出（要"导出"权限）先预览：会导出几条、排除几条、为什么（撤回了、裁图失败、同一张图两种写法、
同一张图重复只留一份）。ZIP：

| 路径 | 内容 |
|---|---|
| `crop_img/s_0001.png` | 小图，文件名只是编号 |
| `rec_gt.txt` | 每行：图片路径、Tab、图中原文（UTF-8，无 BOM）。PaddleOCR `SimpleDataSet` 直接读 |
| `manifest.jsonl` | 每条：图片、原文、OCR 读的、分类、标签、模板、字段、单据编号（导出里重新编的 g_0001）、来源、OCR 版本 |
| `README.md` | 数量、分类、怎么在 PaddleOCR 里读 |

不带原文件、整页 OCR、真实文件名、审核人。导出记审计日志（`ocr_samples:export`）。
